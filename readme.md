# Mind Mapping: Audit Internal

Website mind map untuk meresume materi Audit Internal yang dibuat oleh **Wignyo Pri Atmaja** (NIM: 2407020054 / Kelas: AKT 24 E).

## 📋 Deskripsi

Website ini berisi mind map interaktif yang merangkum materi Audit Internal dengan 4 cabang utama:
1. **Peran dan Definisi Audit Internal**
2. **Model Pertahanan Tiga Lini (Three Lines Model)**
3. **Standar Global Audit Internal (5 Domain Utama)**
4. **Proses Kerja Audit (Siklus Audit)**

## 🚀 Cara Deploy di Netlify

### Metode 1: Deploy via Drag & Drop (Paling Mudah)

1. Kunjungi [Netlify Drop](https://app.netlify.com/drop)
2. Login atau buat akun Netlify
3. Drag & drop folder proyek Anda (yang berisi `index.html`, `styles.css`, dan `netlify.toml`)
4. Website akan otomatis di-deploy!

### Metode 2: Deploy via Git (Recommended)

1. **Persiapkan Repository Git:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Mind Map Audit Internal"
   ```

2. **Push ke GitHub:**
   ```bash
   git remote add origin https://github.com/username/repo-name.git
   git branch -M main
   git push -u origin main
   ```

3. **Deploy di Netlify:**
   - Login ke [Netlify](https://app.netlify.com)
   - Klik "Add new site" → "Import an existing project"
   - Pilih GitHub dan pilih repository Anda
   - Build settings akan otomatis terdeteksi dari `netlify.toml`
   - Klik "Deploy site"

### Metode 3: Deploy via Netlify CLI

1. **Install Netlify CLI:**
   ```bash
   npm install -g netlify-cli
   ```

2. **Login ke Netlify:**
   ```bash
   netlify login
   ```

3. **Deploy:**
   ```bash
   netlify deploy --prod
   ```
